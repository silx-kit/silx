# CLAUDE.md

The guidance for coding agents working in this repository lives in **`AGENTS.md`**, so that
every tool reads the same instructions. The same holds for skills which live in `.agents`

**Read `AGENTS.md` before working on this repository.** It covers the build and test
commands, the architecture of the package and the conventions to follow.

**Read `.agents/skills` before working on this repository.** It contains instruction on
how to work with the project and correct issues.
